# 강사·기술튜터 온보딩

팀스파르타 AX교육팀 신규 강사·보조강사 온보딩 자료입니다.

👉 **[수강생용 온보딩 페이지 바로가기](https://leebuyong.github.io/Onboarding-for-deployment/)**

👉 **[온보딩 진행 체크리스트(Noiton) 바로가기](https://app.notion.com/p/teamsparta/3ca2dc3ef51480e8ae77f7e42f564655?v=1c82dc3ef514836486c688b6c7023261&source=copy_link)**

| 파일 | 용도 |
| --- | --- |
| `index.html` | **수강생용 온보딩 페이지.** 온보딩 당일 화면 공유용이자, 이후 교육 배정 때마다 확인하는 레퍼런스 |
| `온보딩_진행_체크리스트.md` | **운영자용 진행 순서표.** 노션에 붙여넣어 사용 |
| `10월_적용_추가반영.md` | 10월 R&R 확정 후 페이지에 넣을 항목. 확정 전까지 안내 금지 |

온보딩은 웹페이지 **하나만** 띄우고 위에서 아래로 스크롤하며 진행합니다. 체크리스트의 세션 순서 = 페이지 스크롤 순서이며, 각 세션의 📺 표시가 그때 보여줄 섹션입니다.

## 페이지 구성

```
Step 1 온보딩 세팅 (Slack · 교무실)
Step 2 내 역할과 책임 (기술튜터 / 강사 / 겸임)
Step 3 파일럿 배정 기간
Step 4 레벨과 계약 (파일럿 연장 조건 · 계약 문서 · 9월 합류자 안내)
Step 5 현장 유의사항
Step 6 협업 기준 · 아웃보딩
Step 7 지원 · 정산 · 문의
참고   대표 교육과 주로 쓰는 툴
FAQ · 자주 쓰는 링크
```

## 배포

1. 저장소를 **Public**으로 만들고 `index.html` 을 루트에 업로드
2. **Settings → Pages** → Source `Deploy from a branch` → `main` / `/ (root)` → Save
3. `https://<계정>.github.io/<저장소>/` 에서 열립니다

수정은 GitHub에서 `index.html` 을 열고 연필(✏️) → `Commit changes`. 1분 안에 반영됩니다.

## 진행

- 페이지에 회차 정보가 없으므로 **매 회차 그대로 재사용**합니다
- 노션 체크리스트를 회차마다 복제해 맨 위 표(일자·형태·진행자·참석 예정)만 채웁니다
- 출석은 진행자가 직접 확인합니다 (오프닝에서 명단 대조, 종료 전 한 번 더)
- 오프라인 120분 회차는 체크리스트 하단 배치를 따릅니다

## 채워 넣어야 할 자리

페이지에 점선 박스로 표시되어 있습니다. `Ctrl+F` 로 id를 찾아 그 블록을 내용으로 교체하세요.

| id | 내용 | 상태 |
| --- | --- | --- |
| `slot-courses` | 대표 교육 유형·레벨·주 사용 툴 | 반영 완료 |
| `slot-outboarding` | 아웃보딩(활동 검토) 기준 | 반영 완료 (Ver.2.0) |

현재 비어 있는 자리는 없습니다.

## 회차 후 업데이트

- 반복된 질문 → FAQ에 추가
- 새 현장 피드백 → Step 5에 **익명화해서** 추가 (고객사명·강사명 금지, “이런 피드백이 있었습니다 → 그래서 이렇게 해주세요” 형식 유지)
- 시간이 모자라거나 남은 구간 → 체크리스트 분 배분 조정
- 파일럿·아웃보딩 기준이 개정되면 Step 3·4·6을 먼저 최신화 (버전 표기 확인)
- `10월_적용_추가반영.md` 의 선행 조건이 끝나면 해당 항목을 페이지에 삽입

> **중복 없이 한 곳에** — 같은 내용은 가장 적합한 섹션에 한 번만 쓰고, 다른 곳에서는 `#앵커` 링크로 연결합니다. 내용을 추가하실 때도 이 원칙을 지켜주세요.

> **금액 비공개 원칙** — 레벨별 시급은 이 페이지에 표기하지 않습니다. 외부 노출 방지를 위해 별도 내부 운영 가이드에서만 안내합니다.
